# 安全检查与本地化修改记录

日期：2026-10-29 至 2026-10-30。对象：当前工作区源码、本地构建依赖及本次生成的 APK。

## 本地运行边界

当前版本不使用授权、遥测、更新、支付或远程规则服务。
五个原 Git 子模块已迁为普通源码目录，构建只读取 `third_party/maven`，
Gradle wrapper 只读取本地 ZIP，默认离线。SDK 和 JDK 缺失时不自动下载。
旧 CI、私有工具链引用及会恢复在线 wrapper 的维护模板均已清理或修正。
依赖来源、原始提交与工具版本见 [本地构建说明](OFFLINE_BUILD.md)。

Android、Root 与兼容的 Xposed/LSPosed 仍是运行环境。Compose、Room、
Kotlin、协程等第三方库保留本地副本，没有声称全部重新实现或完成源码审计。
Hook 在宿主进程运行，因此同时删除了其使用的遥测与远程规则传输实现。
2026-10-30 新增手动 HTTPS WebDAV 备份，因此 APK 恢复 INTERNET 权限；
网络传输仅允许备份客户端使用。账号通过 Android Keystore 加密后保存在
noBackupFilesDir，不写入备份。协议与使用范围见 [WebDAV 备份](WEBDAV.md)。

## 已处理的问题

| 问题 | 修改后的行为 |
|---|---|
| 远程授权限制本地处理 | 删除授权 SDK、Maven 源、地址、公钥、激活 UI 和租约协调器；保留本地框架健康检测 |
| 默认或可重新启用的遥测上报 | 删除遥测传输、导出器、端点和执行器；兼容事件接口不发送数据，不再生成安装标识，旧设置不能启用上报 |
| 远程更新及支付服务依赖 | 删除更新和支付模块及相关设置入口，不再下载或请求安装 APK |
| 远程规则与旧缓存影响规则内容 | 生产入口始终读取随 APK 打包的规则；保留本地自定义规则导入，忽略旧远程源及缓存配置 |
| 隐私政策依赖外部网页 | 政策作为 APK asset，通过非导出的本地 Activity 展示 |
| 根据 Relay 安装状态阻断 UI / Hook | 移除禁用本模块的行为 |
| 自动输入广播暴露验证码和令牌 | 先定向系统包，失败后定向模块包；系统和无障碍接收端验证每次安装的 IPC 令牌 |
| 备份导出或覆盖内部认证状态 | 导入导出排除 IPC 令牌、内部迁移键及旧远程控制配置；升级时轮换旧令牌，禁用系统自动备份及设备迁移 |
| Provider 通知泄露带令牌的 URI | 返回值与通知移除 query，错误信息不输出原始 URI |
| 短信误删除及同会话批量已读 | 使用完整号码、完整正文、原始时间戳及已知订阅 ID，只操作再次核对过的单条收件箱记录 |
| 保存成功但清理失败后重复插入 | 保留清理失败不再把已完成的插入报告为失败 |
| 导入内容可导致内存或解压资源耗尽 | 限制输入字节数、ZIP 条目数量、单项大小与累计解压大小 |
| 规则路径穿越或通过符号链接越界 | 拒绝绝对路径、编码分隔符及穿越路径，规范化后检查目录包含关系 |
| 规则缓存替换失败损坏旧缓存 | 校验元数据、数量、大小与哈希后替换，失败时保留原缓存并传播取消 |
| 数据库备份恢复损坏现有数据 | 先暂存并检查 SQLite 文件头及 quick_check；关闭、替换及重新打开失败时回滚，处理 WAL/SHM，无法回滚时保留恢复副本 |
| Windows 换行导致内置规则校验失败 | 索引按原始字节计算大小和 SHA-256；Git 属性固定规则 JSON 的 LF 换行，测试覆盖 LF 与 CRLF |
| 规则工具依赖 pip 下载 | 使用 Python 标准库校验当前 Schema 子集、正则和样例，拒绝不支持的 Schema 扩展及远程引用 |
| FileProvider 目录过宽及明文网络 | 共享目录收窄为日志与备份，删除更新目录；两个渠道均禁用明文流量 |

`SecretCodeReceiver` 的现有用途是通过拨号代码打开设置，未据此判定为恶意后门。
本次删除的是已发现的远程控制和数据外传能力，不据此推断上游作者的意图。

## 已知限制

尚未在真机 / LSPosed 环境验证系统输入、无障碍回退、通知和不同 ROM 的短信
Provider 行为。测试及源码检查不能证明所有缺陷和后门均已消除，也不代表已审计
第三方二进制、Android、Root 管理器或框架。旧版 APK 和上游服务器的数据不受
本次本地修改控制。

短信 Provider 必须提供原始 `date_sent`，或在其为 0 时提供完全相同的接收时间。
号码国家码变化、ROM 改写正文或无法确认身份时，会保守跳过删除 / 已读操作。
导出的日志及备份仍可能包含敏感信息；明文日志只有显式构建参数才能启用。

本次交付为本地 Debug 签名。发布 Release 需自行提供签名，原版签名与本地签名
不同的 APK 通常无法直接覆盖安装。迁移工作区时须保留 `third_party/` 和本地
JDK / Android SDK，或自行提供匹配工具。
